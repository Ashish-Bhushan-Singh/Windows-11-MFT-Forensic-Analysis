## Evidence Handling

All screenshots should be captured from the actual investigation environment.

Before uploading screenshots:

- Remove personal information.
- Hide usernames and private file paths.
- Do not expose passwords or sensitive information.
- Do not upload the raw MFT file.
- Do not upload complete disk images.

These screenshots provide visual documentation of the MFT forensic investigation and support the written findings.
